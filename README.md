# YoWord Code Samples

I believe these files effectively demonstrate my coding skills. These are production files used in the YoWord application that are responsible for determining the user's subscription status.

## 1. `[MOBILE] GetSubscriptionStatusRequest.kt`
- **Type:** Mobile Application Code (Kotlin)
- **Purpose:** Provides complete and comprehensive information about the user's subscription status, accounting for all possible variations based on data received from the Google Play Service installed on the device and information retrieved from the YoWord server.

## 2. `[SERVER] get_subscription_status_3.py`
- **Type:** Backend Endpoint Code (Python / FastAPI)
- **Purpose:** Provides complete and comprehensive information about the user's subscription status, accounting for all possible variations based on data received from the Google Play API and a custom user list on the YoWord server.
